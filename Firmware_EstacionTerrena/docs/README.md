# Documentación del firmware

La documentación del código se genera con Doxygen desde la carpeta raíz del
proyecto:

```powershell
doxygen Doxyfile
```

Abre `docs/doxygen/html/index.html` para consultar la página principal, las
interfaces de los módulos y las funciones del firmware. El archivo `Doxyfile`
contiene la configuración de entrada y salida.
