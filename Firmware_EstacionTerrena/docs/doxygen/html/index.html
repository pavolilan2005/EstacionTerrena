ASTRA I - Estación receptora LoRa

El ESP32 recibe paquetes SX1278, mantiene el último dato en el panel web Wi-Fi y envía el paquete más reciente a la pantalla ST7789. La recepción de radio corre en una tarea prioritaria; la interfaz gráfica se actualiza en una tarea separada mediante un buzón FreeRTOS de un elemento, evitando que el tiempo de dibujo detenga la recepción.

Hardware y pines

SPI compartido: SCK GPIO18, MISO GPIO19, MOSI GPIO23. SX1278: CS GPIO5, RESET GPIO14, DIO0 GPIO26. ST7789: CS GPIO15, DC GPIO2, RESET GPIO4. Ambos módulos se alimentan a 3.3 V y comparten GND.

Formato de telemetría

Se recomienda una carga ASCII con campos separados por espacios, por ejemplo SEQ:1234 TBME:24.6 PRES:1012 HUM:48 GAS:120000 AX:0.01 AY:0.02 AZ:0.99 GX:-2.8 GY:-1.0 GZ:0.5 TM:26.7. Los nombres aceptados y unidades se describen en el código de la interfaz. SEQ permite estimar pérdidas.

Acceso Wi-Fi local

El receptor crea el AP ASTRA-I-RX; el panel se abre en http://192.168.4.1. SSID y contraseña configurables se encuentran en wifi_web.c.
