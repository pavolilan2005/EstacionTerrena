esp_err_t display_init ( void )

Inicializa SPI2, el panel ST7789 y los recursos de transferencia.

Inicializa el controlador ST7789 en el bus SPI compartido.

Returns
ESP_OK al inicializar; error ESP-IDF si SPI, semáforo o panel falla.

La orientación aplica espejo horizontal para que la imagen vertical del módulo concreto se lea correctamente. El bus SPI debe estar libre antes.

void display_show_packet ( const lora_packet_t * packet)

Analiza los campos del payload, actualiza telemetría y refresca valores.

Actualiza los valores y el historial a partir del paquete recibido.

Los campos reconocidos usan pares CLAVE:valor o CLAVE=valor; las claves se comparan sin distinguir mayúsculas. Los campos ausentes conservan su último valor, pero no se presentan como inválidos una vez vistos.
