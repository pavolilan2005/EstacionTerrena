◆ lora_sx127x_init()

esp_err_t lora_sx127x_init ( void )

Configura el bus SPI y el SX127x, y comienza recepción continua.

Inicializa GPIO/SPI, programa el perfil de radio y habilita RX continuo.

Returns
ESP_OK al inicializar; un error de ESP-IDF si falla la configuración.

Configura el bus SPI y el SX127x, y comienza recepción continua.

Returns
ESP_OK al completar el arranque; error ESP-IDF ante cualquier fallo.

Perfil actual: 433 MHz, BW 125 kHz, SF7, CR 4/5, CRC y sync word 0x12.

◆ lora_sx127x_receive()

bool lora_sx127x_receive ( lora_packet_t * packet)

Lee un paquete disponible sin esperar bloqueado por una recepción.

Comprueba DIO0 y copia un paquete LoRa disponible desde la FIFO.

Parameters
[out]packetEstructura donde se almacenan la carga y metadatos.
Returns
true si se recibió un paquete; false si aún no hay uno disponible.

Lee un paquete disponible sin esperar bloqueado por una recepción.

Returns
true para un paquete válido; false si no hay RxDone o hubo error CRC.

Esta rutina es de sondeo: no espera a que llegue un paquete, para permitir que la tarea de radio atienda periódicamente otras tareas del sistema.
